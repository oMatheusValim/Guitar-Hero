1. Comando para puxar da nuvem as novas informações do repositório, se existirem
git pull origin main

2. Adicionar qual arquivo deseja enviar para o repositório
git add <caminho para arquivo ou . para todos>

3. Comentar as modificações
git commit -m "seu comentário"

4. Enviar para o repositório
git push origin main

Excluir a pasta build 
rm -rf build

Refazer a pasta build
mkdir build

Compilar o arquivo CMake e juntar tudo nele
cmake ..

Salvar as alterações
make

Rodar o programa
./guitar_hero
